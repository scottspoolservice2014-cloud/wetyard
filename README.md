# WetYard

WetYard.com is a problem-first yard drainage directory and matching experiment for Florida's Treasure Coast.

V1 goal: turn a homeowner's confusing yard-water symptom into the right category of local help, then prove the funnel with one qualified lead.

## V1
- 13 indexable pages
- problem-first finder
- tagged Treasure Coast provider roster
- manual lead routing
- mobile-first static site

Deployment and domain connection are intentionally separate from the source build.
